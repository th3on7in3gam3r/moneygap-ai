# Money Gaps™ and Fix Paths™

A **Money Gap™** is a concrete miss on your site — weak CTA, thin trust, crawl blockers, missing buyer-intent pages, or AI discoverability holes. MoneyGap names it, frames impact as an **AI Estimate**, and gives you a **Fix Path™**.

## Anatomy of a gap

- **What’s missing** — the specific miss
- **Why it matters** — business context
- **Business impact** — narrative plus AI Estimate when available
- **Difficulty / time** — planning cues for your team
- **Fix Plan** — suggested actions by tier

## Using a Fix Path™

1. Open the opportunity from a report or Action Center.
2. Read What’s missing and Why it matters before jumping to code.
3. Use **How to fix → Code + AI** for an IDE Prompt when the change is implementation-heavy.
4. Apply changes on a branch or draft — MoneyGap never auto-publishes.
5. Mark progress in-product only after you have verified the live change.

## Developer Mode and IDE Prompt

For engineering Fix Paths™, IDE Prompt copies a ready-made prompt for Cursor, Claude, or your IDE — including the target website — so you do not guess which site the gap belongs to.
