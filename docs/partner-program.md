# Partner Program™ & Creator Economy

## Phase

Phase 22 Marketplace™.

## Partners

Partner Directory™ lists agencies, developers, integrators, and educators (`marketplace_partners`). Verified badge is editorial, not a legal certification.

## Creators

`marketplace_creators` profiles attach to listings. Creators see install counts, ratings, and stub revenue attribution in Marketplace Analytics™.

## Revenue sharing

- `revenueShareBps` on creator + `marketplace_revenue_events` ledger stubs.
- Figures are **AI Estimate** / attributed analytics only.
- **Live Stripe Connect payouts and paid listing checkout are out of scope** for Phase 22 (future).

## Ratings & reviews

Community Ratings™: one review per workspace per listing; aggregates update listing `ratingAvg` / `ratingCount`.

## Downloads / installs

Install count increments on successful workspace install (free listings in Phase 22).
