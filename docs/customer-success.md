# Customer Success Center™

## Mission

Help new workspaces reach first value quickly: interactive onboarding, help, sample reports, and links into Academy / Docs.

## Phase

Phase 23 Platform 1.0™.

## Surfaces

| Surface | Role |
| --- | --- |
| `/dashboard/success` | Onboarding checklist, help, sample CTA |
| `/dashboard/docs` | Documentation Center™ |
| Marketplace Academy | Compose Phase 22 courses (`/dashboard/marketplace`) |

## Onboarding steps

1. Analyze a website
2. Open a report / Money Gaps
3. Create an Action Project or Fix Path
4. (Agency) Invite a teammate or client
5. Review Launch Center readiness (owners)

## Product tours

Lightweight in-app step list (not a third-party tour vendor). Empty/loading states on Success / Docs / Launch.

## Knowledge base

Documentation Center curated index of `/docs` markdown. Deep links to vision, engine, billing, API, security, operations.
