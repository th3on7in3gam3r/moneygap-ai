# Privacy Center™

Route: `/dashboard/settings/privacy` (linked from Settings).

## Sections

- Cookie Preferences (Smart Consent™)
- Consent Timeline™
- Cookie Intelligence™ inventory (search/filter)
- Connected Integrations (status)
- Stored Data Summary (counts)
- Download My Data (`GET /api/privacy/export`)
- Delete My Account (Clerk + support path — no silent wipe)
- Privacy FAQ
- Security / processors / third-party summary

## APIs

- `GET/POST /api/privacy/consent`
- `GET /api/privacy/cookies`
- `GET /api/privacy/center`
- `GET /api/privacy/export`
