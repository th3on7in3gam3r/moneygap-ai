# Backlink Engine™

## Mission

Evaluate referring domains, authority trends, link diversity, and outreach opportunities for MoneyGap’s own domain.

## v1 status

No Ahrefs/Moz (or similar) provider is wired. Backlink Health™ returns:

- `score: null`
- Clear `unavailableReason`
- A setup finding with Fix Path™ to connect a provider

**Never fabricate domain authority or referring-domain counts.**

## Future

When a provider is connected, populate diversity, lost links, anchor distribution, and outreach suggestions into Self Optimization findings.
